# GAWA website

The GAWA app website is a Next.js site highlighting hiring, jobs, equipment
rentals, activity tracking, messaging, and GAWA Points. The Android installer
is served as `public/gawa.apk` and downloads as `gawa.apk`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Update the Android download

Copy the latest release APK to `public/gawa.apk`. The download button and modal
link to this file.
